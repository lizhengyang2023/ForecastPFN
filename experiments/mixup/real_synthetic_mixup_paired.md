# 周期与相位受控 Mixup 试验计划

更新：2026-10-29。当前实现与运行命令见 [统一 Mixup README](../mixup/README.md)。原随机配对和带回退的 `period_only` / `period_phase` 属于历史协议，结果不并入本次受控对照。

## 1. 问题与正式数据集

本实验检验：在**周期相近**的真实训练锚点与伙伴之间，相位匹配是否比相位不匹配更有利于预测；再比较真实伙伴与模拟伙伴的效果。固定训练、验证、测试时间切分，伙伴检索只使用训练窗口历史 `X`，测试集只用于最终评估。

正式测试数据集暂定为 **ETTh1、ETTh2、Electricity、Traffic、Weather**，各数据集使用原有单变量任务、窗口长度和预测长度。**Exchange 和 Illness 暂时排除在本轮训练、验证、测试及跨数据集结论之外**，不计入正式结果表或“无效”结论。本地小规模准备检查（每任务 32 条模拟序列）中，Exchange 共同合格锚点仅 131/5,202（约 2.5%），Illness 为 0/559；Illness 的可靠真实周期窗口比例为零。在当前可靠性与共同支持规则下，无法对它们进行有解释力的相位对照。小规模诊断不代表正式模拟池下其他五个数据集的最终覆盖率，正式准备阶段仍须逐一检查。

Exchange、Illness 的弱周期或周期难以从当前历史长度识别的问题留待**独立后续研究**。届时可另行考虑非周期特征、较长历史或自适应选择规则，并建立新协议和输出目录；本轮不为纳入它们而临时放宽周期阈值。

## 2. 受控组与信息边界

所有组使用**同一真实训练锚点池**：锚点历史周期可靠，且它在真实伙伴和模拟伙伴中均有相位匹配与不匹配的候选。Real–Real 排除自身及时间上重叠的邻近窗口。所有候选先满足同任务、周期容差和预测跨度累计漂移限制，再按圆周相位距离分组：匹配为 `dφ ≤ π/4`，不匹配为 `dφ > π/4`。每类从至多 8 个候选中按固定 seed 选伴。**不使用周期不匹配的伙伴，也不在候选不足时回退到随机配对。**共同池为空时准备阶段失败并写出诊断。

| 任务 | 训练伙伴 |
| --- | --- |
| `real` | 不混合；在同一共同锚点池上重新训练 |
| `real_real_phase_match` | 周期合格、相位匹配的真实伙伴 |
| `real_real_phase_mismatch` | 周期合格、相位不匹配的真实伙伴 |
| `real_synthetic_phase_match` | 周期合格、相位匹配的模拟伙伴 |
| `real_synthetic_phase_mismatch` | 周期合格、相位不匹配的模拟伙伴 |

只从历史 `X` 提取周期和相位特征；未来 `Y` 仅在选定伙伴后参与标签混合。锚点和伙伴分别按各自历史标准化，`λ` 同时用于历史与未来的逐点凸组合。验证和测试样本不进入伙伴索引。与旧 Real-only 结果相比，共同锚点池改变了训练样本，所以必须使用本协议重训的 `real` 作为基线。

## 3. 固定配置与任务分片

- 五种小模型：Linear、DLinear、MLP、GRU、Transformer；seed 为 42、43、44。
- 增强任务的 `λ ∈ {0.9, 0.75, 0.5}`；`real` 每模型和 seed 只运行一次。增强概率 0.5，batch size 64，训练 2,000 updates，模拟序列池默认 1,024 条。
- 每 100 updates 按真实验证集**原尺度 RMSE**保存最佳模型；测试 MAE、RMSE、MASE 只用于最终报告。模型和 `λ` 的选择不得查看测试结果。
- 分片单位为 `(数据集, 模型, seed, λ, 任务)`，一个 run 独占一张设备；共享模拟资产在准备阶段生成，各 worker 单独写日志和结果目录。

每个数据集为 `5 模型 × 3 seed × (1 Real-only + 4 增强任务 × 3 λ) = 195 runs`；五个数据集完整网格共 **975 runs**。若覆盖率不足，须报告支持度并停止该数据集的机制解释；不得借测试表现调阈值。旧随机 Mixup 可作为注明协议差异的历史参考，不参与本次配对差值计算。

## 4. 执行与判断

1. 运行确定性与端到端测试；准备五个数据集的训练期特征及伙伴池，逐一检查 `support.json` 中可靠率、四类候选覆盖率和共同锚点比例。当前小规模诊断仅支持“值得正式检查”，不保证全部五个数据集有足够支持。
2. 先以 ETTh1 冒烟并正式初筛，核对每个 run 的来源、增强数、有限损失、验证选模和真实尺度评估。然后根据**训练集支持度**决定其余四个数据集是否具备可解释的对照条件；不按测试成绩决定纳入。
3. 对具备支持度的数据集完成相同网格，按同模型、同 seed、同 `λ` 比较匹配与不匹配、真实与模拟伙伴，并与重训的 `real` 比较。报告各任务 MASE、MAE、RMSE 与按 seed 配对差值；不同量纲的原尺度 MAE/RMSE 不直接跨数据集平均。
4. 只有相位匹配组在多个 seed、模型和数据集上稳定胜过相位不匹配组，才能支持相位约束有效；模拟组还需与同条件真实组对比，才能讨论模拟语料的增量价值。微小或不稳定差异只作观察。

复现命令、四卡调度、续跑方式和统一报告路径见 [统一 Mixup README](../mixup/README.md)。
