# 单数据集正式初筛：Exchange Rate

实验使用 Exchange Rate 的 `0` 列，输入 96 天、预测 14 天；真实数据按时间固定分成 70%/10%/20%，对应 5,202/746/1,505 个训练/验证/测试窗口。每个模型在 3 个 seed 和 9 个合成占比上各训练 2,000 次更新，共完成 135 次运行。下面的 MAE、RMSE 都在原始数据尺度上计算；`best` 权重由真实验证集 RMSE 选择。比例在每个模型内按 **3 seed 平均验证 RMSE** 选择，不使用测试集选比例。

| 模型 | 验证集选出的合成占比 | best 测试 MAE | best 测试 RMSE |
|---|---:|---:|---:|
| Linear | 0% | 0.009485 | 0.013281 |
| DLinear | 0% | 0.009365 | 0.013358 |
| MLP | 12.5% | 0.010029 | 0.013844 |
| GRU | 0% | 0.009344 | **0.013151** |
| Transformer | 12.5% | 0.009638 | 0.013326 |

无需训练的基线：last 的 MAE/RMSE 为 **0.009196/0.013253**，seasonal naive（周期 7 天）为 0.011318/0.015340，历史均值为 0.023058/0.030399。GRU 的 `final` 权重在 0% 合成时取得 0.009248/0.012988，但这不是按验证集挑选的最优权重；last 仍有略低的 MAE。

就本任务而言，大多数模型随着合成占比提高而退化，100% 合成尤其明显。MLP 和 Transformer 的 `best` 比例虽由验证集选为 12.5%，其测试 RMSE 分别比各自 0% 合成组略高约 0.18% 和 0.04%。这说明小幅验证优势没有稳定转化为测试优势，不能据此声称混合数据有益。`final` 权重下 MLP 和 Transformer 的验证选比与 `best` 不同；完整曲线和两个 checkpoint 均保留在生成报告中。

运行复核通过：135 次运行的预测指标由保存的预测数组独立重算；同模型/seed 的初始权重一致，真实切分、每批来源数量、逐窗口曝光和验证集选权重均符合协议。5 个单元测试通过。实际训练分两段完成，总计约 28 分钟，设备为 NVIDIA GeForce RTX 4060 Laptop GPU。以正式初筛计时外推，七数据集 945 次运行约 **2.44 小时**，规划区间 **1.71–4.39 小时**；估算依赖本机硬件和模型形状校正，未计首次合成生成、排队和绘图，不能视为保证耗时。

本地生成的完整报告在 `experiments/results/mixed_exchange/report/report.md`，包含最终/最佳权重的全部比例曲线、模型对比、学习曲线、预测实例和 ForecastPFN 原生成器的采样实例；`aggregate.csv` 与 `runs.csv` 保留全部比例和 seed 的结果。大型运行产物被 Git 忽略，远程运行会重新生成。

该初筛是**单目标、单数据集**结论。所有比例共享完整真实训练窗口池，但真实窗口在梯度更新中的曝光随合成占比减少；因此高合成比例变差不能单独归因于合成模式质量。3 个 seed 只反映训练/抽样变异，重叠测试窗口也不是独立样本。100% 合成仍使用真实验证集选权重，不能称为严格零样本。
