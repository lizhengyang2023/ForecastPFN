# 统计匹配的独立合成样本扩充实验

## 问题与边界

保持 `sample_mixed` 的单数据集训练、70/10/20 时间划分、历史归一化、固定 batch 来源配额、2,000 updates、真实验证 RMSE 选择 checkpoint 和真实测试评估。每个样本是完整的真实或合成窗口；不做 Mixup。只用真实训练段决定合成池；验证集用于选择方案，测试集只报告。

## ForecastPFN 原生成器可调范围

`generate_series.generate(n, freq_index, start, options, random_walk)` 的公开入口支持长度、频率、起始日期、`options` 和随机游走开关；当前 `options` 并未被 `make_series` 使用。`Config.transition` 控制两条生成序列在序列内部过渡，基线固定为 false；本实验也固定 false，`random_walk=false`。生成器内部在 `__generate` 中抽取 `ComponentScale` 与 `ComponentNoise`：线性趋势系数、指数趋势基数、小时/周/月/年/分钟季节幅度、趋势相位偏移、Weibull 噪声形状 `k` 与噪声幅度 `scale`；谐波系数由 `get_freq_component` 抽取。当前入口没有直接传这些参数的接口。

参数校准方案在每条序列生成时修改其采样后的 `SeriesConfig`，再交给原 `make_series` 生成；保留原趋势、季节、Weibull 和谐波公式。可调的首批倍率为 `trend`（线性系数与指数基数偏离 1 的幅度）、`seasonal`（该频率启用的季节幅度）、`noise`（噪声 scale）。起始日期、相位、Weibull `k` 和谐波系数维持原随机先验。倍率从预先声明的小网格选择，以训练窗口的统计距离为依据；不用验证/测试目标调倍率。原始组使用倍率 1。倍率仅改变生成参数，不把真实值注入合成序列。

## 合成池构造

每个数据集独立构造目标大小为 4,096 窗口的固定池。原始组直接沿用旧协议：1,024 条独立序列、每条 4 窗口。筛选组先生成 5 倍候选，再按历史 X 特征挑选。参数组使用训练统计选择倍率后直接生成；组合组使用同样倍率及同样候选预算再筛选。所有组的最终池大小、窗口数和训练预算相同，各组使用独立缓存及签名。筛选组需要额外生成成本，报告中单列；它与原始组的比较回答“多花生成成本做筛选是否改善预测”，不能单独归因于相同生成预算下的筛选操作。

特征均来自历史 X：历史归一化后去趋势的 rFFT 功率，汇总低/中/高频和预设季节邻域的功率比例；再加趋势斜率、差分波动、滞后相关和尾部强度。对训练分布的各特征用中位数/IQR 缩放并截断极端距离。筛选时先按真实训练特征的低/中/高周期能量分层，再在各层选距离最近的候选；每条生成序列最多保留 4 窗口。报告每组特征分位数、标准化分布距离、候选接受率及独立序列数。频谱相近只表明 X 的边际形态相近，需在真实测试上检验 X→Y 预测是否受益。

## 实验矩阵与判定

组别：`original`、`filtered`、`parameter`、`parameter_filtered`；同一组中 `p=0` 是真实数据基线。第一轮在 ETTh1、Weather、Exchange 上用 Linear、DLinear、MLP，3 seed，`p={0,.25,.5,.75}` 初筛。正式扩展至 7 数据集、5 模型、3 seed、上述 4 个比例；更细比例只在初筛有稳定信号后追加。Exchange/Illness 的周期可能弱，季节功率不设硬门槛。

训练 run 使用 `(dataset, strategy, model, seed, p)` 独立目录。同一数据集/模型/seed/p 下配对比较策略；相同模型/seed 的初始化一致。比较真实测试 MAE/RMSE/MASE 与 `original` 和 `p=0` 的差值；选择策略、模型与 p 只依据真实验证 RMSE。另报告池统计距离、生成成本、曝光和运行时间。初筛看各数据集的配对方向和 seed 离散度；不因少量漂亮的测试点挑选阈值。全量结果按数据集呈现，跨数据集只汇总相对变化。

## 运行与核验

先用统一 `run.py --corpus --stage prepare` 准备，随后 `launch.py` 多卡启动器按完整 run 分片，资产仅在准备阶段写入。`run.py` 不加 `--corpus` 时保留原始实验协议。重复命令可跳过同签名已完成 run；源代码或配置变化须换输出目录。统一 `verify.py` 根据元数据检查完整网格、来源曝光、初始化、保存预测和池大小；统一 `summarize.py` 输出逐 run/聚合/验证选择 CSV，统计距离与 MASE 对照图。冒烟只验证流程和报告，不作为效果结论。具体命令见本目录 README，数据根目录统一记为 `$DATA_ROOT`。
