# 周期与相位配对的真实—模拟 Mixup 试验计划

更新：2026-10-28。状态：方案设计，配对实验尚未实现。工作位置为 `experiments/mixup_paired/`；随机配对的协议与实现见 [`../mixup/real_synthetic_mixup.md`](../mixup/real_synthetic_mixup.md) 和 [`../mixup/README.md`](../mixup/README.md)。下述阈值是实施候选值，正式训练前须依据训练集诊断冻结，不以测试结果调整。

## 1. 已知结果与要回答的问题

现有 Mixup 以真实训练窗口为锚点，随机抽一个同任务真实或模拟窗口，对历史 `X` 与未来 `Y` 使用同一个固定 `λ` 逐点凸组合。两个窗口分别按各自历史标准化，但其周期、相位和趋势可能错位。反相周期项线性组合可能压低振幅，并让混合目标难以预测。

随机配对的 Exchange Rate 汇总中，真实—模拟组的测试 MASE 在伙伴权重 10% 时与 Real-only 很接近，在 50% 时明显较差。这只是单任务观察，不能直接归因于相位错配。见
-  [`../results/mixup_exchange/report/compact_mase.md`](../results/mixup_exchange/report/compact_mase.md)。

本实验检验：**只用训练窗口的历史估计周期与相位，优先选择结构相近的伙伴，能否减少混合形态的破坏并改善真实预测？** 将“仅周期相近”与“周期加相位相近”分开比较。每个增强位置仍由一个真实锚点和一个伙伴组成；伙伴可在不同更新中重复使用，不要求全局唯一配对。

## 2. 数据、信息边界与 Mixup 定义

沿用原实验的七个单变量任务、时间切分、`L/H`、真实训练窗口、固定模拟池、历史标准化、模型和评估方式。仅对**真实训练窗口**与同任务模拟窗口建检索索引；验证和测试不进入索引。特征只能由历史 `X[:L]` 计算，不能读取真实或模拟 `Y`，也不能利用验证/测试指标决定伙伴。模拟未来只在选中伙伴后用于构造混合标签。

每个被增强位置仍执行：

```text
Zr = concat(Xr_norm, Yr_norm)
Zp = concat(Xp_norm, Yp_norm)
Zm = λ Zr + (1−λ) Zp,  λ ∈ {0.9, 0.75, 0.5}
(Xm, Ym) = split(Zm, L)
```

`p` 可以是真实训练伙伴或模拟伙伴。`λ` 对历史、目标和整个窗口固定；`p_aug=0.5`，每个 batch 的 64 个真实锚点中 32 个增强、32 个保持原样。第一版**只选择窗口，不平移、裁切、重采样或旋转伙伴序列**；这样与随机 Mixup 的差别仅在选伴规则。验证/测试预测仍用对应真实历史窗口的统计量反标准化。分别标准化使数值尺度可比，但不会自动消除季节振幅、趋势或未来转折差异。

## 3. 周期与相位的训练期估计

新增 `period_features.py`，为各候选窗口预计算周期 `P`、相位 `φ`、周期振幅 `A` 与可信度。时间索引统一以**历史最后一个观测点为 `t=0`**、过去为负；因此相位比较指向预测起点附近的周期位置，而非文件中的绝对行号。不同采样频率不互配。

1. 对标准化历史去线性趋势，再计算功率谱。候选周期限制在预先指定的任务范围，且历史中至少覆盖约 **3 个完整周期**。用谱峰相对背景的强度与对应滞后的自相关核查可靠性；12 与 24 等谐波并存时不能只取最高峰而误判周期。
2. 对可靠周期，在该频率对去趋势历史做正余弦投影，复系数辐角定义为 `φ`，模长定义为 `A`。圆周相位距离 `dφ = |angle(exp(i(φr−φp)))| ∈ [0,π]`；周期距离 `dP = |log(Pr/Pp)|`。另核对预测跨度内的累计漂移 `2πH|1/Pr−1/Pp|`，防止当前相位接近、未来逐渐错位。
3. 保存周期置信度、趋势斜率与残差能量。振幅先作为诊断，不在主实验中硬性筛选，以免同时改变多个因素。近常数、无显著周期或周期过长的窗口标记为**不可靠**，不伪造相位。

小时任务的 `L=96` 覆盖 4 个 24 小时周期；Exchange 的 `L=96` 虽覆盖多个 7 天周期，汇率未必有可靠周季节性；Illness 的 `L=104` 对 52 周周期仅有 2 轮，按主规则往往回退。任务季节周期（小时 24、Exchange 7、Illness 52）只是候选，不是强制估计结论。阈值须在训练集特征分布和已知周期的合成样本上校准并冻结。

## 4. 伙伴检索、回退与公平对照

新增 `partner_index.py`。先按同任务、同频率、同 `L/H` 过滤。主实验可从宽松周期门槛 `|Pr/Pp−1| ≤ 0.1` 开始，同时限制预测跨度漂移；周期加相位组再要求 `dφ ≤ π/4`。这些是实施前待冻结的候选值，需先报告各任务的覆盖率。合格候选按周期/相位距离排序后，从前 `k=8` 个用固定 seed 抽一个，避免反复选择唯一最近邻；`period_only` 只按周期筛选，在合格集合中随机抽样，不看相位。Real–Real 必须排除自身，并记录或排除高度重叠的邻近窗口。

无可靠周期或无合格候选时明确回退：`period_phase → period_only → random`；`period_only → random`。记录每层实际覆盖率、候选数和回退原因。若绝大多数位置回退，结果不能被解释为相位匹配的效应。索引建立后不依模型损失或测试表现更新。

使用与旧实验相同的真实锚点流和增强位置；新随机流只用于候选选择。保存锚点 ID、伙伴 ID、距离、回退层级、伙伴曝光及唯一伙伴数。匹配可能让少数伙伴过度曝光，应单独诊断，必要时增加等曝光消融。

| 组别 | 增强位置的伙伴规则 | 回答的问题 |
|---|---|---|
| Real-only | 不混合；复用同配置结果 | 原始语料基准 |
| Random Real–Synthetic | 现有随机模拟伙伴 | 同预算随机基准 |
| Period-only Real–Synthetic | 周期相近，忽略相位 | 周期筛选是否有用 |
| Period+Phase Real–Synthetic | 周期与预测起点相位均相近 | 相位约束是否有额外价值 |
| Random / matched Real–Real | 同样的三种规则用于真实训练伙伴 | 区分匹配效应与模拟来源效应 |

主网格先比较三种 Real–Synthetic 规则；Real–Real 配对作为第二阶段机制消融。各组对齐模型、seed、`λ`、`p_aug`、锚点曝光、优化器、更新次数与验证选择规则。复用旧结果前核对数据、模拟池、模型与训练配置签名；不一致则另建输出目录重跑基线。旧样本级混合仅作为注明预算差异的外部参照。

## 5. 推进顺序

1. **训练集可行性与协议冻结**：先对 Exchange、ETTh1、Illness 统计可靠周期比例、合格候选数、相位覆盖率、预期回退率及特征计算成本；用可控正弦、趋势加噪、谐波和反相样本验证估计器。冻结周期范围、置信门槛、`k` 和回退规则。若 Exchange 没有足够可靠周期，先在 ETTh1 等周期更明显的任务检验机制，不为覆盖率降低门槛。
2. **实现和确定性测试**：复用 `experiments/utils/` 的数据、模拟池、模型和评估模块；在 `mixup_paired/` 增加 `period_features.py`、`partner_index.py`、`sampling.py`、`diagnostics.py` 与独立配置、运行、核验入口。检验相位圆周距离、周期可信度、谐波、回退、自身/重叠排除、相同 seed 重放，以及特征计算不读取 `Y`。保留旧 `mixup/` 代码与结果不变。
3. **冒烟**：在 ETTh1 与 Exchange 各取 1 个 seed、Linear/GRU、`λ=0.75`、50 updates，运行随机、仅周期、周期加相位组；检查同权重混合 `X/Y`、有限 loss 与梯度、训练来源、实际增强数、回退日志和真实尺度评估。冒烟指标不用于选配置。
4. **正式初筛**：优先在候选覆盖充分的任务上，5 模型 × 3 seed × 3 权重 × 2 个新增 Real–Synthetic 策略 = **90 个新增 runs/任务**；随机组的 45 runs/任务只在签名一致时复用，否则重跑。每组 2,000 updates、batch=64。先看真实验证集及机制诊断，再决定扩展任务和 Real–Real 的两个配对策略（另 90 runs/任务）。实际回退占主导的任务不能算作有效相位实验。
5. **针对性消融**：若相位组优于仅周期组，再比较严格/宽松相位门槛及 `k`，并控制伙伴曝光集中度；若只有高 `λ` 有效，检查低 `λ` 的目标不相容及振幅压缩；若模拟组有收益，用同强度 Real–Real 配对检验模拟信息的增量价值。参数选择只用训练诊断和真实验证，不使用测试。

## 6. 选择、指标与结论门槛

- 与随机 Mixup 一致：每 100 updates 依据**真实验证集原尺度 RMSE**保存 `best`，训练满 2,000 updates 并保存 `final`。各模型/任务的策略和 `λ` 根据相同 seed 集合的平均验证 RMSE 选择；测试集仅在选择冻结后报告。
- 报告测试 MAE、RMSE、MASE、逐预测步误差及相对同模型 Real-only、Random Real–Synthetic 的按 seed 配对差值。沿用 [`../mixup/summarize.py`](../mixup/summarize.py) 的比例比较口径，增加按策略分组的伙伴权重曲线。不同量纲任务不直接平均原始 RMSE。
- 机制诊断报告可靠周期比例、候选数、回退率、`dP/dφ` 与未来累计漂移、伙伴覆盖和重复曝光、混合前后周期振幅及历史/未来标准差，并与随机组对照。**距离变小是配对操作成功；预测误差变小才是任务收益。**
- 若周期加相位组只胜随机组、未胜仅周期组，只能支持周期筛选；若还稳定胜仅周期组，才支持相位约束的增量价值。若模拟组也稳定胜同强度的真实—真实配对组，才进一步支持模拟模式提供额外信息。单数据集、单权重或低覆盖率下的微小差异仅作筛选信号。

## 7. 实现依赖、文献关系与交付物

第一版无需新增第三方包。已有 `numpy` 可用 `numpy.fft.rfft/rfftfreq`、`numpy.angle`、`numpy.random.default_rng` 计算谱、相位和确定性抽样；已有 `scipy` 可用 `scipy.signal.periodogram`、`scipy.signal.find_peaks`、`scipy.signal.detrend` 估计周期、检查谱峰并去趋势。批量预计算并按数据与配置哈希缓存特征，避免每个 batch 重算。数据量增大时先用周期分桶和 NumPy 向量化检索，再判断是否需要额外近邻库。[NumPy FFT 文档](https://numpy.org/doc/stable/reference/generated/numpy.fft.rfft.html) · [SciPy periodogram 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.periodogram.html)

凸组合操作与 [Chronos 的 TSMix](https://arxiv.org/html/2403.07815v1) 最接近，但本实验对真实与模拟窗口做有监督的 `X/Y` 同权重混合，并在组合前按周期/相位选伴，不能称为 Chronos 的原始配方。结构目标与 [ReGeN](https://arxiv.org/abs/2606.05264) 的相位对齐周期骨架相近；本实验没有学习残差生成器或跨变量依赖图，属于更简单的配对增强消融。[ReAugment](https://proceedings.mlr.press/v306/yuan26i.html) 强调选择有用的增强位置/策略，但其依据模型反馈学习策略，并非本方案的固定频谱匹配。

交付物：独立可复现的配置与运行签名、训练期特征缓存、可审计的配对/回退日志、确定性与冒烟核验、验证/测试预测和指标，以及与随机 Mixup 并列的汇总报告。若实现时改动窗口标准化或混合操作，应另立实验协议和输出签名，不混入本配对消融。
